# Internal maintainer archive

This directory is **not** part of the public OSM documentation.

It preserves the development decision register, accepted and
superseded model decisions, the architecture freeze record, and
historical working notes.

Public users should start at the repository root `README.md`.

| Path | Contents |
|------|----------|
| `decisions/` | Decision register and OSM-M / freeze records |
| `notes/` | Historical compatibility and compliance working notes |
| `investigation/` | Reference-estate stress test (2026-09-13). Public examples: `examples/reference-estate/`. |
| `example-enterprise-analysis.md` | Working notes for onboarding the predecessor catalog into `examples/reference-enterprise/`. |

Do not treat files here as the current public explanation of OSM.

The current model is defined by `schema/`, `SPECIFICATION.md` and
`MODEL.md`. Public framework documentation is `models/`. Public
compliance documentation is `compliance/`.
