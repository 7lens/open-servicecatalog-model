# ISO/IEC 27701

- **Status:** NOT ANALYZED
- **Universe:** OSM-C-001 (compliance / governance)
- **OSM schema fields today:** optional stack `mappings.iso27701`;
  optional offering `iso27701_pii_role`, `iso27701_pii_categories`,
  `iso27701_retention_days`

These fields are reference mappings. They are **not** a PIMS and not
a claim of ISO/IEC 27701 compliance.

## 1. Framework overview

ISO/IEC 27701 extends ISO/IEC 27001/27002 with privacy information
management (PIMS) guidance for PII controllers and processors.

## 2. Relevant scope for technological services

Later analysis should ask which privacy facts a technological
service or offering can carry (role, data categories, retention)
without OSM becoming a processing-activity register (RoPA).

## 3. OSM concepts/attributes relevant to the framework

Present in the current schema (not yet analyzed as a mapping):

## 5. Missing information

NOT YET ANALYZED.

A full 27701 programme needs organization-level roles, processing
purposes, data-subject rights operations and more. OSM does not
currently model those.
